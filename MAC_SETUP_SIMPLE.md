# Easy Book Buzz Setup for Mac

## Super Simple (Best for Non-Tech Users)

### Step 1: Install Python (if not already installed)
- Go to: https://www.python.org/downloads/
- Click the big download button
- Run the installer
- Takes 2 minutes, just click "Next"

### Step 2: Run Book Buzz
- Give your friend the `BookClub` folder
- They find `START_MAC.command` file in it
- They double-click it
- A terminal window opens, then a browser window with Book Buzz
- Done!

---

## If START_MAC.command doesn't work

They can open Terminal and run:
```
cd ~/Downloads/BookClub
python3 run_web.sh
```

Then open browser to: http://localhost:5000

---

Upload a CSV ballot file and analyze. The app does all the work.
